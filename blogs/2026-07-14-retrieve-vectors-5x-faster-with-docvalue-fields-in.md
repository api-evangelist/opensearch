As vector search workloads scale, retrieving vectors from search results becomes a bottleneck. Vector retrieval using doc values in OpenSearch 3.7 bypasses the expensive _source vector reconstruction path, delivering 5.5x faster end-to-end retrieval and 14.7x faster server-side performance.
