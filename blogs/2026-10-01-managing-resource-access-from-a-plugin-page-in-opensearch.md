OpenSearch 3.9 adds resource sharing controls to plugin pages in OpenSearch Dashboards, so you can see and change who can access a detector, monitor, or model group from the list where you already find it. Plugin developers can add the same controls with a single placeholder element and no dependency on the Security plugin.
